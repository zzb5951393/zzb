# 《探知者》蛇类竞技网页原型

这是一个不依赖联网、不依赖打包工具、无外部图片/音频资源的俯视角 2D 蛇类竞技游戏原型。玩法从传统方格贪吃蛇升级为类似 Slither.io 的平滑移动竞技：玩家用鼠标控制蓝色蛇，在循环地图里吃果子成长、加速抢资源、用身体封路击杀敌人，并尝试达到胜利长度。

## 本地运行

最简单的试玩方式：解压项目后直接双击 `index.html`，浏览器会打开游戏页面。

如果后面要频繁修改代码，推荐用本地服务器运行：

```bash
python3 -m http.server 5173
```

然后在浏览器打开：<http://localhost:5173>

也可以执行：

```bash
npm run start
```

## 当前玩法

- 启动后先进入主菜单，点击“开始游戏”进入正式游戏。
- 设置面板可以选择窗口大小：自适应、1024×1024、1280×720、1920×1080、2048×2048，并可选择草地或沙漠主题。
- 玩家蛇固定为蓝色、无条纹，由卡通圆球组成，初始长度为 3。
- 鼠标指向哪里，蛇头就平滑朝哪里移动；按住鼠标左键进入加速状态。
- 加速最多连续约 5 秒，能量耗尽后按每秒约 10% 恢复，HUD 中显示能量条。
- 地图大小为 4000×4000，采用循环边界，摄像机跟随玩家蛇头。
- 场上保持 10 条蛇：1 条玩家蛇 + 9 条 AI 敌人蛇。
- 敌人有贪吃型、攻击型、保守型、游荡型等性格，会找果子、规避危险、争夺资源或干扰玩家。
- 果子包括普通果子、大果子、加速果子、诱饵果子，全部由 Canvas 代码绘制。
- 蛇头撞到其他蛇身体会死亡；敌人撞到玩家身体时，玩家击杀数 +1。
- 玩家达到胜利长度后显示胜利提示，可继续挑战或结算。
- 玩家死亡或主动结束后显示结算：时间、长度、历史最高长度、吃果数、击杀数等。

## 代码架构

```text
index.html                    # 页面入口、主菜单、设置、HUD、结算弹窗
src/main.js                   # 应用装配、菜单流程、主循环、HUD、结算
src/styles.css                # 响应式布局、菜单、HUD、弹窗、游戏外观
src/game/config.js            # 地图、速度、蛇数量、果子类型、AI 性格等配置
src/game/state.js             # 连续坐标游戏状态、AI、果子、碰撞、胜利/结算规则
src/game/input.js             # 鼠标、左键加速、触屏方向与加速输入
src/game/renderer.js          # Canvas 渲染层，代码绘制背景、蛇、果子、边缘提示
scripts/check-modules.mjs     # 本地 JS 语法检查
```

### 为什么这样拆分

- **规则和渲染分离**：`state.js` 只处理玩法状态和规则，`renderer.js` 只负责画面。
- **输入适配独立**：`input.js` 把鼠标、左键、触屏输入统一成方向和加速状态。
- **配置集中**：地图大小、速度、AI 数量、果子类型、胜利面积比例都在 `config.js`，方便继续调参。
- **资源零依赖**：蛇、食物、背景都由 HTML/CSS/Canvas 代码绘制，不依赖 png/jpg/mp3 等二进制资源。

## GitHub PR 合并冲突

如果 GitHub 显示 `This branch has conflicts that must be resolved`，不要直接在网页里混合保留两套核心游戏文件。推荐关闭旧的冲突 PR，使用最新重新创建的干净 PR。更详细的说明见 [`docs/github-pr-troubleshooting.md`](./docs/github-pr-troubleshooting.md)。
