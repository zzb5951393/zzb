# 《探知者》蛇类竞技网页原型

这是一个不依赖联网、不依赖打包工具、无外部图片/音频资源的俯视角 2D 蛇类竞技游戏原型。玩法从传统方格贪吃蛇升级为类似 Slither.io 的平滑肉鸽竞技：玩家用鼠标控制蓝色蛇，在循环地图里吃经验、升级抽卡、安装炮塔、强化身体，并与 AI 蛇混战。

## 本地运行

最简单的试玩方式：解压项目后直接双击 `index.html`，浏览器会打开游戏页面。

如果后面要频繁修改代码，推荐用本地服务器运行：

```bash
python3 -m http.server 5173
```

然后在浏览器打开：<http://localhost:5173>

也可以执行：

```bash
npm run start
```

## 当前玩法

- 启动后先进入主菜单，点击“开始游戏”进入正式游戏。
- 设置面板可以选择窗口大小、草地/沙漠主题，并支持音效开关与总音量调节。
- 玩家蛇固定为蓝色、无条纹，由卡通圆球组成，初始长度为 3；每个圆球都有独立血量。
- 鼠标指向哪里，蛇头就平滑朝哪里移动；按住鼠标左键进入加速状态。
- 加速最多连续约 5 秒，能量耗尽后按每秒约 10% 恢复，HUD 中显示能量条。
- 地图大小为 4000×4000，采用循环边界，摄像机跟随玩家蛇头。
- 场上保持 10 条蛇：1 条玩家蛇 + 9 条 AI 敌人蛇。
- 经验豆替代旧版果子：1/5/10/20/50 点经验豆会被蛇头附近自动吸附。
- 每 100 点经验升 1 级；玩家升级时暂停并出现三选一卡牌，敌人升级时自动选卡。
- 卡牌可获得身体增长、机枪塔、散弹枪塔、激光塔、炮塔强化、血量、护盾、修复、速度、经验磁铁等效果。
- 炮塔自动安装到身体槽位，最多 10 个，会自动搜索敌方身体圆球并攻击。
- 自己撞自己不会死亡；蛇头撞到其他蛇身体仍然死亡，击杀归属给被撞身体所属蛇。
- 身体圆球被打爆后会从蛇身移除，圆球上的炮塔或护盾也会消失。
- 玩家达到胜利长度后显示胜利提示，可继续挑战或结算。
- 玩家死亡或主动结束后显示结算：时间、等级、长度、炮塔、经验、击杀数等。

- 地图中加入 3 个毒云区，蛇身体进入毒云后会从尾巴开始持续受伤。
- 地图中加入 2 个固定毒蘑菇 Boss，Boss 会发射子弹、环形弹幕并周期性吐经验。
- Boss 死亡会掉落大量经验、宝箱，并有概率掉落无敌或巨大化道具；Boss 会在一段时间后刷新。
- 宝箱会给经验并可能额外生成稀有道具；无敌可短时间免疫伤害和碰撞死亡，巨大化会放大体型并提高伤害。

## 代码架构

```text
index.html                    # 页面入口、主菜单、设置、HUD、结算弹窗
src/main.js                   # 应用装配、菜单流程、主循环、HUD、结算
src/styles.css                # 响应式布局、菜单、HUD、弹窗、游戏外观
src/game/config.js            # 地图、速度、蛇数量、经验豆、卡牌、炮塔、毒云、Boss 等配置
src/game/state.js             # 连续坐标游戏状态、AI、经验、升级、卡牌、炮塔、毒云、Boss、道具规则
src/game/input.js             # 鼠标、左键加速、触屏方向与加速输入
src/game/renderer.js          # Canvas 渲染层，代码绘制背景、蛇、经验豆、炮塔、毒云、Boss、子弹、边缘提示
scripts/check-modules.mjs     # 本地 JS 语法检查
```

### 为什么这样拆分

- **规则和渲染分离**：`state.js` 只处理玩法状态和规则，`renderer.js` 只负责画面。
- **输入适配独立**：`input.js` 把鼠标、左键、触屏输入统一成方向和加速状态。
- **配置集中**：地图大小、速度、AI 数量、经验豆密度、炮塔数值、卡牌稀有度都在 `config.js`，方便继续调参。
- **资源零依赖**：蛇、经验豆、炮塔、子弹和背景都由 HTML/CSS/Canvas 代码绘制，不依赖 png/jpg/mp3 等二进制资源。

## GitHub PR 合并冲突

如果 GitHub 显示 `This branch has conflicts that must be resolved`，不要直接在网页里混合保留两套核心游戏文件。推荐关闭旧的冲突 PR，使用最新重新创建的干净 PR。更详细的说明见 [`docs/github-pr-troubleshooting.md`](./docs/github-pr-troubleshooting.md)。
