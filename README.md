# 《探知者》蛇类肉鸽竞技原型

这是一个无需联网、无需打包工具、无需外部图片/音频资源的本地网页游戏原型。游戏采用 HTML/CSS/JavaScript Canvas 实现，所有蛇、经验豆、炮塔、毒云、Boss、宝箱和特效都由代码绘制。

## 本地运行

最简单方式：直接双击 `index.html`，浏览器会打开游戏页面。

推荐方式：在项目目录运行本地静态服务器：

```bash
npm run start
```

然后浏览器打开：

```text
http://localhost:5173
```

## 当前玩法

- 鼠标控制蛇头方向，按住鼠标左键加速。
- 玩家蛇为蓝色，无条纹；敌人蛇有不同颜色和装饰。
- 地图为 4000 × 4000 px 循环世界，摄像机跟随玩家。
- 场上保持 10 条蛇：1 条玩家蛇 + 9 条 AI 蛇。
- 普通经验豆不会直接增加长度，而是提供经验。
- 升级需求使用递增曲线：`floor(100 * Math.pow(1.2, level - 1))`，中后期升级会明显变慢。
- 玩家升级时暂停并弹出三选一卡牌；敌人升级时自动选择卡牌。
- 炮塔上限为 10 个，安装在身体槽位上。
- 炮塔类型包括：机枪塔、散弹枪塔、火焰炮塔、激光塔、导弹塔。
- 激光塔已削弱为 350 px 短中距离精准输出，DPS 约比机枪塔高 20%。
- 火焰炮塔会喷出 60 度扇形火焰，最多命中 6 个敌方部位，并附加 5 秒燃烧。
- 散弹枪会发射多颗扇形弹丸，并可通过“散弹扩容”卡增加弹丸数量。
- 导弹塔会发射慢速追踪导弹，命中或撞到障碍物后产生范围爆炸。
- 每个身体圆球都有独立血量、护盾、燃烧状态和脱战回血计时。
- 头部被炮塔/Boss/毒云/燃烧打到 0 血时，如果蛇还有身体则进入“头部受损”并减速；如果只剩头部则会死亡；撞到其他蛇身体仍会立即死亡。
- 每个身体部位 5 秒未受伤后会自动回血，回血类卡牌可以强化该机制。
- 升级会让蛇体型按曲线逐渐变大，体型、碰撞和武器/护盾视觉同步成长。
- 毒云区面积扩大，并按外圈/中圈/核心分层刷新更高价值经验和宝箱。
- 第一章 Boss 现在包含 5 个资源点：2 个毒蘑菇 Boss、机械能量核心 Boss、火焰人 Boss、毒蛇 Boss。
- 毒蘑菇 Boss 会攻击附近蛇、释放环形弹幕、周期性吐经验，并定期显示红色范围预警后发动 50% 最大血量重击。
- 机械能量核心 Boss 是固定型中级 Boss，会持续旋转并释放八方向能量弹幕和短预警高伤害光波。
- 火焰人 Boss 会移动追踪目标，留下燃烧路径，释放火球雨和多红圈炎爆。
- 毒蛇 Boss 是第一章最高威胁 Boss，会移动追踪、冲刺、释放毒雾和螺旋毒弹。
- 地图加入固体障碍物和冰冻减速区域；障碍物能阻挡蛇、子弹、激光、火焰、导弹和 Boss 范围攻击。
- 左上角中文战斗播报会提示玩家升级、获得护盾/炮塔、进入毒云/冰区、Boss 预警、身体破碎和死亡原因。
- 稀有道具包括无敌和巨大化。
- 结算界面会展示等级、长度、炮塔、击杀、经验、Boss 击杀和纪录。

## 操作

- 鼠标移动：控制方向。
- 鼠标左键按住：加速。
- 升级弹窗：点击 3 张卡中的 1 张。
- 右下角“结束本局”：主动结算。

## 设置

开始界面点击“设置”可以调整：

- 窗口大小：自适应、1024×1024、1280×720、1920×1080、2048×2048。
- 地图主题：普通草地、沙漠。
- 音效开关。
- 总音量。

## 代码结构

```text
index.html                    # 页面入口、菜单、HUD、弹窗
src/styles.css                # 响应式布局、菜单、HUD、卡牌样式
src/main.js                   # UI 绑定、游戏循环、音效、结算
src/game/config.js            # 游戏数值、炮塔、Boss、经验、地图配置
src/game/input.js             # 鼠标/触控输入与加速输入
src/game/state.js             # 核心模拟：移动、AI、经验、升级、战斗、Boss、毒云、回血
src/game/renderer.js          # Canvas 绘制：蛇、血条、护盾、炮塔、Boss、毒云、道具
scripts/check-modules.mjs     # JS 语法检查脚本
```

## 开发检查

```bash
npm run check
```

该命令会对 `src` 和 `scripts` 目录下的 JavaScript 文件执行 `node --check`。

## 资源说明

本项目当前不包含 png、jpg、mp3 等外部资源文件。图片表现全部由 Canvas/CSS 绘制，音效由 Web Audio API 动态生成。
